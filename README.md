## Descripción
Sistema bancario en Java con herencia y encapsulamiento:
- `CuentaBancaria` (clase base)
- `CuentaAhorro` (hereda de CuentaBancaria)
- `CuentaCorriente` (hereda de CuentaBancaria)
- `CoreBanca(main)` (pruebas)

## Instrucciones para compilar y ejecutar

Desde la carpeta donde están los archivos:

    javac *.java
    java Main
